# ใส่โมเดล .glb (เช่นจาก Meshy) ในหน้า RATCH 3D

หน้า `ratch-business-3d.html` ใช้โมเดลที่ประกอบด้วยโค้ดเป็นค่าเริ่มต้น และจะสลับเป็นไฟล์ `.glb` ให้เมื่อกำหนดไว้

1. สร้างโมเดลแบบ low-poly และส่งออกเป็น `.glb` (แนะนำไม่เกิน ~1 MB ต่อไฟล์)
2. ตั้งชื่อตามชนิดโรงไฟฟ้า: `ccgt`, `ccgtOld`, `spp`, `coal`, `hydro`, `wind`, `road`, `mix`
3. วางไว้ในโฟลเดอร์ `models/` ข้างไฟล์ HTML
4. เพิ่มบรรทัดนี้ก่อนสคริปต์หลัก (หรือแก้ `MODELS` ตอนต้นสคริปต์):
   `window.RATCH_MODELS={ccgt:'models/ccgt.glb', coal:'models/coal.glb'};`
5. หน้าเว็บจะปรับขนาดให้พอดีแผ่นฐานเอง (กว้างไม่เกิน 1.3 และสูงไม่เกิน 2.6 หน่วย) วางฐานโมเดลที่ระดับพื้น และใส่ปล่องควันที่ยอดโมเดลสำหรับชนิด ccgt, spp, coal

ถ้าโหลดไฟล์ไม่สำเร็จ หน้าจะใช้โมเดลที่ประกอบด้วยโค้ดต่อไป
